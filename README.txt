# Confession Prank V2

Standalone, offline-ready interactive confession prank.

## Kasama
- index.html
- styles.css
- script.js

## Paano buksan
I-extract ang ZIP at i-double-click ang `index.html`.
Walang npm, framework, server, o external asset na kailangan.

## Features
- Mobile-first modern dark UI
- 9 interactive “what if” stages
- Typing animation
- Choice gates para hindi ma-skip agad
- Progress bar
- Suspense pause screen
- Final fake confession countdown
- Confetti prank reveal
- Restart + keyboard controls
- Reduced-motion support
- Fully offline

## Notes
Ang page ay intentionally playful at fictional. Walang data collection o network request ang JavaScript.
